Store Review App - Store Rating Platform

A full stack web application where users can discover stores, rate them (1-5 stars), and store owners can track their ratings. Admin can manage all users and stores.

 Tech Stack Used In Projects
- Frontend: React.js, Vite, Tailwind CSS
- Backend: Node.js, Express.js
- Database:MySQL

 Features
- System Administrator: Add stores, add users (System Administrator / Owner / Normal user), view dashboard with total users, stores & ratings.
- Normal User: Register / Login, search stores by name & address, give / update rating, change password.
- Store Owner: Login, view average rating of own store, see list of users who rated.

 How to Run Locally

 1. Backend
cd Backend
node server.js
Enter this command in VS code terminal
2.Frontend
cd Frontend
npm run dev
Enter this command in VS code terminal
